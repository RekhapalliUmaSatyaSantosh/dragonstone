# Dragonstone

A Game of Thrones themed front-end web project featuring a landing page with login and registration flow.

## Live Preview

Open `index.html` in your browser to view the landing page.

## Pages

- **Landing Page** (`index.html`) — Entry point with "Enter the Kingdom" and "Join the Clan" buttons
- **`home/`** — Main themed page after entry (dragons, houses, warriors, and throne sections)
- **`login/`** — Login page
- **`register/`** — Registration page

## Tech Stack

- HTML5
- CSS3 (custom properties, Flexbox, Grid, responsive design with `clamp()` and media queries)
- JavaScript

## Project Structure

```
dragonstone/

└── README.md
```

## Getting Started

1. Clone the repository
   ```
   git clone https://github.com/RekhapalliUmaSatyaSantosh/dragonstone.git
   ```
2. Open `index.html` in your browser, or serve the folder with a local dev server (e.g. VS Code Live Server)
